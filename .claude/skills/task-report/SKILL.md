## Instruções
Ao concluir uma tarefa:
1. Reúna os arquivos criados e modificados.
2. Anote os testes executados e resultados.
3. Se o Graphify ou buscas de contexto foram usadas, registre nós consultados e assertividade.
4. Crie o arquivo `docs/tasks/YYYY-MM-DD-[feature].md` preenchido.
